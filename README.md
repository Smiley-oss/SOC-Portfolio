# SOC Portfolio

A documented portfolio of my learning and hands-on work towards a career as a SOC (Security Operations Center) analyst. Every project gets a short write-up: the goal, the steps I took, what I found, screenshots and what I learned.

> **Status:** just started. The structure is in place and the first projects are being added. The table below shows what is done and what is coming.

## Why this portfolio
- Show practical skills, not only course certificates.
- Practise writing clear incident and investigation reports, which is a core SOC skill.
- Keep all my security work in one place that employers can read.

## Skills I am building
- Security fundamentals (networks, operating systems, common attacks)
- Log analysis and monitoring with a SIEM
- Detection engineering (writing and tuning detection rules)
- Incident response and reporting
- Threat hunting and advanced threats
- Cloud security, AI security and compliance
