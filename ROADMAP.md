# Roadmap

A simple plan for the four phases. I tick things off as I finish and document them.

## Phase 1: Start Here + Cyber Foundations
- [ ] Networking basics (IP, DNS, ports, common protocols)
- [ ] Windows and Linux basics for security work
- [ ] Core security concepts (CIA triad, common attack types)
- [ ] First write-up in the project format

## Phase 2: SIEM + Detection Engineering + Incident Response
- [ ] Set up a SIEM in a home lab
- [ ] Collect and read logs from Windows and Linux machines
- [ ] Write and test a few detection rules
- [ ] Practise an incident response write-up from alert to report

## Phase 3: Advanced Threats + Threat Hunting
- [ ] Study common attacker techniques and how they show up in logs
- [ ] Run a simple threat hunt and document it
- [ ] Map findings to a known framework such as MITRE ATT&CK

## Phase 4: Cloud + AI + Compliance
- [ ] Cloud security basics
- [ ] Security risks of AI systems
- [ ] Overview of compliance standards and what they ask of a SOC

## Rules for my write-ups
1. Use only systems I own or have permission to test.
2. Remove passwords, tokens, personal data and real IP addresses from screenshots.
3. Explain what I did in my own words.
